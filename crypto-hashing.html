Avalanche Effect

A secure hash must flip ~50% of output bits for every 1-bit input change. This prevents attackers from predicting output patterns.

≈50%
🛡

Collision Resistance

Finding two inputs with the same SHA-256 hash requires ~2^128 operations. At 1 trillion/sec, that's longer than the universe's age.

2^128
🔒

Preimage Resistance

Given a hash output, it's computationally infeasible to find the original input. This one-way property is fundamental to digital signatures.

One-Way
