⚡ When to Use What?

Small arrays (n < 50): Insertion Sort — low overhead, cache-friendly, stable. Large arrays: Merge/Quick Sort — O(n log n) dominates.

🎯 Binary Search Prerequisite

Binary Search requires a sorted array. If your data isn't sorted, you must sort first (O(n log n)) or use Linear Search (O(n)).

📊 The n² Cliff

At n=10,000: O(n log n) ≈ 130K ops. O(n²) ≈ 100M ops. That's 769x slower. This is why algorithm choice matters at scale.
